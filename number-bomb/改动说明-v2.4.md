# v2.4 改动说明（基于 v2.3，含 v2.3 的跳过惩罚补丁）

线上现在是 v2.2，v2.3 还没部署，所以 v2.4 = v2.3 的全部改动 + 下面这个新游戏，一次部署就都上线了。

## 新增：第 4 个游戏「声控飞鸟」`voice-bird/`

- 玩法：对着手机麦克风发声，音调越高小鸟飞得越高，音调越低飞得越低，没声音会慢慢往下掉。前面不断来墙（上下两根柱子中间留个口），穿过去加距离，撞墙就结束。
- 音调怎么测：Web Audio 自相关算法测基频，220Hz 合成音实测测出 222Hz；默认低音 130Hz、高音 440Hz，用对数映射到高度；首页有“测我的低音 / 测我的高音”，哼一声点一下就按你的声音校准。
- 轮流玩：和数字炸弹一样，房主建房（6 位房号，PeerJS 点对点，不经过服务器），两人轮流各飞一局，飞完比谁飞得远（米数 + 穿过几堵墙），最后出冠军。
- 观战不干扰（主人这次特别点的）：只有轮到的人点“开麦克风开始飞”才会开麦克风；对方在观战，麦克风根本没开，画面上也写着“你的麦克风没开，不会干扰对方”。观战的人看到的是轮到的人实时传过来的小鸟位置和墙，不是自己手机在算。
- 没麦克风也能玩：权限被拒 / 没麦克风时，用手指在画面上下拖动代替，照样能飞。
- 自己练：首页有“自己先练一局”，不用建房。

## 改了哪些文件

## 验证（云端，无真机）

- `node --check`：games.js、voice-bird 两段 inline JS 全部通过
- VM 模拟测试通过：高音 440Hz 飞到顶（y=50）、低音 110Hz 掉到底、220Hz 在中间；220Hz 合成音测出 222Hz、静音测不出音调；墙会生成、距离会涨、鸟在缺口外撞墙、在缺口内通过
- 没做过真机测试：麦克风在真手机上的灵敏度、两人联机观战的延迟，都要主人两部手机实测。建议先在安静的地方哼“啊——”由低到高试一次，看小鸟跟不跟得上。

## 部署（与 v2.2 / v2.3 同样方法，旧仓库 Pages 已关，不用再处理）

1. 先 git pull。
2. 把 number-bomb-v2.4 文件夹里面的内容，原样覆盖到仓库 cyberrichlin.github.io 的 number-bomb/ 文件夹。
3. git add、commit、push 到 main，等 1-2 分钟，手机清缓存再打开 https://cyberrichlin.github.io/number-bomb/ ，首页应该有 4 张卡。
