# 数字炸弹 v2.3 改动说明（只改 1 个文件）

## 改了什么
只改 `number-bomb/number-bomb/index.html`，其余 21 个文件与 v2.2 完全一致。

**堵住的口子：结束弹层里的“跳过惩罚”**
- v2.2 里点“跳过惩罚”，房主端直接调 `hostStart()` 开新局，换题次数清零重给 3 次，
  等于绕过了“真心话+大冒险合计最多换 3 次，换满先喝一杯”这条规则。
- v2.3 改成：跳过惩罚 = 先喝一杯。按钮改名“跳过惩罚，先喝一杯”，点后记
  `penaltyDone=true / penaltyDrink=true`，不开新局、不清零换题次数；
  想再玩由房主另点“再来一局”，那时才是新一局、重新给 3 次。
- 非房主点跳过：只提示“跳过要房主记一杯”，不改状态（与“只有被罚的人能换题/
  完成”同一口径，权限仍在房主端）。

## 没动的地方
- 选真心话 / 大冒险那一步仍是谁都能点（主人还没定要不要改成只有被罚的人能点，
  这次没动，默认保持原样）。
- 换题合计 3 次、换种类不重置、关了重开不重置、只有被罚的人能换题/完成、
  牵手题跳过后低频复出，全部与 v2.2 一致。
- 独立真心话大冒险页（truth-dare/）本来就没有“跳过惩罚”按钮，不用改。

## 验证
- 改动前后 diff 只有上述 3 处（按钮文案、新增 hostSkipPenalty 函数、点击分发改路由）。
- 抽出页内两段 inline JS，`node --check` 全部通过。
- 逻辑核对：跳过后房主与加入方都回到“游戏结束”卡片（房主看到“同设置再来一局”，
  加入方看到“等待房主开始新一局”），惩罚层不再重开；“再来一局”仍走 hostStart，
  是唯一重给 3 次的入口。
- 未做真机联机实测：部署后请两人实测——点一次“跳过惩罚，先喝一杯”，确认
  不开新局、不重给换题次数，再点“再来一局”才重新给 3 次。

## 部署（与 v2.2 同样方法，旧仓库 Pages 已关，不用再处理）
1. 先 git pull。
2. 把 number-bomb-v2.3 文件夹里面的内容，原样覆盖到仓库 cyberrichlin.github.io 的 number-bomb/ 文件夹。
3. git add、commit、push 到 main，等 1-2 分钟，手机清缓存再打开验证。
